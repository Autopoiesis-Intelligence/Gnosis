# Gnosis support and feedback

Gnosis is an evolving project. The public repository may not yet provide a released package, hosted service, or guaranteed response time.

- **Report a defect:** [Open a bug report](https://github.com/Autopoiesis-Intelligence/Gnosis/issues/new?template=bug_report.md).
- **Request a capability:** [Open a feature request](https://github.com/Autopoiesis-Intelligence/Gnosis/issues/new?template=feature_request.md).
- **Browse existing work:** [View open issues](https://github.com/Autopoiesis-Intelligence/Gnosis/issues).

When reporting a problem, include the steps to reproduce it and relevant public evidence. Never publish secrets, credentials, or private partner data. Submitting a request does not imply that it has been accepted, scheduled, or implemented.
