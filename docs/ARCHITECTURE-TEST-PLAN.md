# Architecture Test Plan

The first automated gate checks that the trusted Core does not acquire direct dependencies on external production/factory layers, research/context repositories, external AI/connectors, or product/commercial surfaces. Historical repository labels may remain in compatibility tests, but they do not define current roles.

This is an initial lexical guard only. It must later be replaced or supplemented by an AST import graph and runtime boundary tests. A lexical match is a guardrail, not proof of runtime isolation.

The gate also verifies that the canonical Core contract documents exist. Missing contracts are an architecture failure, not a documentation warning.
